# Network Scanning Lab

## Objective
The objective of this lab is to practice network scanning and identify active hosts, open ports, services, and potential security risks on a network.

## Tools Used
- Nmap
- Zenmap
- Linux
- Virtual Machine

## Skills Practiced
- Network discovery
- Port scanning
- Service identification
- Network traffic analysis
- Basic vulnerability identification

## Lab Process
During this lab, I used Nmap and Zenmap to perform network scans in an authorized lab environment. I analyzed the scan results to identify hosts, open ports, running services, and other network information.

## What I Learned
This lab helped me understand how cybersecurity professionals use network scanning tools to discover devices and services on a network. I also learned how open ports and exposed services can help security analysts identify potential security risks.

## Ethical Use
All scanning activities documented in this portfolio were performed in authorized educational lab environments for cybersecurity training purposes.
